# ScreenGuide Assistant — 实时屏幕操作引导

## 功能

- **逐步引导** — 在网页上画圈、箭头、聚光灯，一步步告诉你点哪里
- **自由标注** — 鼠标点击任意位置画红圈/箭头/高亮框
- **截图捕获** — 一键截图，复制到剪贴板或下载
- **URL 自动检测** — 访问 Facebook Ads Manager 等页面时，自动弹出横幅提示引导
- **独立窗口** — 点击图标打开独立窗口，不会随点击消失

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角打开 **"开发者模式"**
3. 点击 **"加载未打包的扩展程序"**
4. 选择 `screen-guide-extension` 文件夹
5. 点击 **"选择文件夹"**
6. 完成！工具栏出现蓝色时钟图标

## 使用

### 打开面板
点击 Chrome 工具栏的 **蓝色时钟图标** → 打开独立窗口（不会消失）

### 操作指南
1. 在面板里选 **"操作指南"** 标签
2. 点击一个指南（如"Facebook: 更换主页身份"）
3. 网页上会出现**蓝色圆圈**告诉你点哪里
4. 面板里点 **"下一步"** 继续

### 自动检测
访问 Facebook Ads Manager 时，页面顶部会自动弹出蓝色横幅：
> "检测到你在 Facebook Ads Manager，是否需要更换主页身份的指导？"

点击 **"开始引导"** 即可自动启动。

### 自由标注
1. 选 **"自由标注"** 标签
2. 点击工具（聚光灯/高亮/画圈/箭头）
3. 在网页上点击任意位置进行标注

### 截图
1. 选 **"截图"** 标签
2. 点击 **"截图"** 按钮
3. 预览出现后，可复制到剪贴板或下载

## 故障排查

**Q: 点击图标没反应？**
A: 请确认已经移除旧版本的 ScreenGuide，然后重新加载。

**Q: 网页上没有出现蓝色圆圈？**
A: 刷新页面后再试。某些 SPA 页面（如 Facebook）需要切换标签页后再回来。

**Q: 截图失败？**
A: 确保当前标签页不是 chrome:// 或 file:// 页面。截图需要 https/http 页面。

**Q: 自动检测横幅没出现？**
A: 刷新 Facebook 页面，或手动点击图标打开面板。首次加载可能需要刷新一次。
